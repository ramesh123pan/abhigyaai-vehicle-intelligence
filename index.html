API Documentation

Connect approved external applications to the protected RC lookup service.

Endpoint

GET /api/v1/external/rc/{registration_number}

Live endpoint: /api/v1/external/rc/UP16FA0981

Local development: http://127.0.0.1:4173/api/v1/external/rc/UP16FA0981

Authentication

Send the assigned secret key with every request:

X-API-Key: vdesk_your_key

Bearer authentication is also supported. Never place keys in frontend JavaScript or public repositories.

Response behavior

The service checks MySQL first. A valid cached record is returned without a paid provider call. If no valid cache exists, Way2API is called, the response is stored, and the result is returned.

Key controls

  • Per-minute rate limit
  • Daily request quota
  • Optional expiry date
  • Optional IP allowlist
  • Separate key per application and revocable access

Example request

curl -H="X-API-Key: vdesk_your_key" /api/v1/external/rc/UP16FA0981

Common responses

200 Vehicle result400 Invalid registration number401 Missing or invalid API key403 Expired key or IP not allowed429 Rate limit or daily quota exceeded
